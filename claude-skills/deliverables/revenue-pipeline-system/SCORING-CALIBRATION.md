# Scoring calibration — what the numbers mean

Use this when scoring feels arbitrary — for you, Claude, or buyers.

## Problem Severity (0–25)

| Range | Meaning |
|-------|---------|
| 0–8 | Annoyance; workaround exists |
| 9–16 | Material cost (time, revenue, risk) |
| 17–22 | Executive attention; repeated failures |
| 23–25 | Existential (major client loss, audit failure, layoffs tied to ops) |

**Consultant context:** “Spreadsheet pipeline” for a $2M agency = **16–20**, not 25 unless revenue already falling.

## Buying Signal (0–20)

| Range | Meaning |
|-------|---------|
| 0–5 | Static company; no public motion |
| 6–12 | Content/hiring hints |
| 13–17 | Active hiring in sales/ops/marketing; new leadership |
| 18–20 | RFP, public “we’re scaling,” budget line visible |

## Ability to Pay (0–15)

| Range | Meaning |
|-------|---------|
| 0–5 | Solo / early; price-sensitive |
| 6–10 | SMB with team |
| 11–15 | Mid-market; history of buying consultants/agencies |

Use **employee band + client logos + funding** — never guess revenue.

## Service Fit (0–15)

| Range | Meaning |
|-------|---------|
| 0–5 | None of your catalog rows fit |
| 6–10 | Partial fit; would custom-scope |
| 11–15 | Clear **Matched Service** from catalog |

If fit &lt; 8, consider **disqualifying** regardless of total score.

## Accessibility (0–10)

| Range | Meaning |
|-------|---------|
| 0–3 | No name; gatekeepers only |
| 4–6 | Champion possible; buyer unclear |
| 7–10 | Named economic buyer or strong intro path |

## Urgency (0–10)

| Range | Meaning |
|-------|---------|
| 0–3 | “Someday” |
| 4–6 | Quarter goal |
| 7–10 | Dated event (board meeting, launch, contract end) |

## Competitive Pressure (0–5)

| Range | Meaning |
|-------|---------|
| 0–1 | Unique niche |
| 2–3 | Alternatives exist (other agencies, DIY) |
| 4–5 | Commodity; RFP-heavy |

## Tier discipline (consultant ICP)

| Tier | Weekly action |
|------|----------------|
| HOT | Contact this week; executive time |
| HIGH | Sequence + follow-up within 10 days |
| MEDIUM | Nurture / one touch |
| WATCH | Research only or archive |

**Rule:** If **Accessibility ≤ 4** and **Buying Signal ≤ 8**, cap tier at **MEDIUM** even if pain is high.
