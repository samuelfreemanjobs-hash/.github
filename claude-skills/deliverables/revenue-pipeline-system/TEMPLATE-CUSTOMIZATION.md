# Template customization — consultant edition

After duplicating HUNTER, adjust **Industry** (and optionally **Company Size**) so the template matches B2B consultants, not automotive suppliers.

## Industry — add or replace select options

In **Opportunities → Industry** field, include:

- Professional Services / Consulting  
- Marketing / Creative Agency  
- Dev / IT Services Agency  
- SaaS (B2B)  
- Fractional / Executive Services  
- Other  

You can **hide or remove** automotive-specific options in the **customer template only** (keep them in your internal HUNTER base).

## Service Catalog — Target Verticals

Replace industrial tags with e.g.:

- Professional services  
- Agencies  
- B2B SaaS  
- Fractional executives  

## Seed data

1. Paste **7 rows** from `SERVICE-CATALOG-CONSULTANTS.md`.  
2. Paste **3 rows** from `EXAMPLE-OPPORTUNITIES.md`.  
3. Create views from `VIEWS-TO-CREATE.md`.

## Outreach Log

Leave empty except optional **one** example row linked to Northline (shows linkage) — or keep empty for cleanliness.
