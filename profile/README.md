# Base44

These repos provide developer tools and examples for working with Base44's backend service and integrating with Base44 apps.

## Resources

- [Documentation](https://docs.base44.com/developers/landing)  
- [Roadmap](https://feedback.base44.com/roadmap)

## Repositories

| Repo | Description |
| :---- | :---- |
| [cli](https://github.com/base44/cli) | Command-line interface for creating and managing projects using Base44's backend service |
| [javascript-sdk](https://github.com/base44/javascript-sdk) | JavaScript SDK for Base44 services |
| [apps-examples](https://github.com/base44/apps-examples) | Example applications |
| [skills](https://github.com/base44/skills) | AI agent skills for Cursor and Claude Code |
